# Flameshot (green fork)

A personal Windows build of Flameshot with three changes:

- **Span all monitors.** A setting in Configuration → General lets one capture overlay cover every monitor, as Flameshot did before v14, instead of choosing a single monitor first. It handles monitors with different scale factors and heights.
- **Mouse cursor in every screenshot.** The pointer is drawn into the captured image wherever it was at the moment of capture.
- **Green icon.**

The original project is Flameshot: https://github.com/flameshot-org/flameshot
